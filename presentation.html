🎨 Presentation Layer (css/)
Organized into 5 dedicated CSS stylesheets separating global design tokens, animated aurora gateways, responsive grid layouts, SVG styling, and print rules.
⚡ Logic & Controller Layer (js/)
Decoupled into 6 specialized ES6+ modules separating data persistence, authentication flows, academic grade algorithms, D3 SVG pipelines, and DOM UI bindings.
📊 Data Layer (data/)
Independent JSON data source with multi-tier storage caching (LocalStorage → SessionStorage → In-Memory Fallback) ensuring zero session data loss.

Department Performance Bar Graph & D3.js Pipeline
Live D3 SVG Chart
📊 Department Comparison Chart
🔍 D3.js Bar Graph Architecture
  • 1. Aggregate Rollup (`d3.rollup`): Calculates mean scores per department across all 22 cohort students in real time.
  • 2. Coordinate Scaling: d3.scaleBand() positions department categories; d3.scaleLinear() scales scores [0, 100] to SVG pixel height.
  • 3. Gradient SVG Injection: Applies dynamic SVG gradient fills and hover brightness animations.
  • 4. Animated Transitions: Bars rise smoothly from Y=0 with .transition().duration(750) on load and filter changes.
💡 Interactive Demo: Click the buttons above the chart to toggle between Average Marks and Pass Percentage!

🖨️ Official Marksheet Modal & Print Layout
  • • Autonomous Institutional Header: Embeds college emblem, serial numbers, examination session, and student metadata.
  • • Subject-Wise Evaluation Matrix: Calculates Max Marks (100), Min Qualifying Marks (35), Marks Secured, and Letter Grades.
  • • UGC Formula Calculation: Computes Semester Grade Point Average: SGPA = Σ(C_i × GP_i) / Σ(C_i)
  • • High-Fidelity @media print: Clean A4 page formatting, official border styling, controller signatures, and institute seal.
